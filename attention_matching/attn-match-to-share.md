Файл с обученным кешем это `torch.save` словарь такого вида:

```python
{
    "format_version": 1,
    "meta": {...},
    "layers": [
        {"c1": Tensor, "beta": Tensor, "c2": Tensor},   # layer 0
        {"c1": Tensor, "beta": Tensor, "c2": Tensor},   # layer 1
        ...
    ]
}
```

### Смысл тензоров

Для каждого слоя:

- `c1` — компактные **keys**
- `c2` — компактные **values**
- `beta` — bias для attention, который нужен только нашему инференсу; если другой метод его не использует, его можно игнорировать

То есть для инициализации другого метода сжатия контекста нужно брать именно:

- `K_init = c1`
- `V_init = c2`

### Размерности

Типично формы такие:

- `c1`: `(B, KV, T, D)`
- `c2`: `(B, KV, T, D)`
- `beta`: `(B, KV, T)`

где:

- `B` — batch size, обычно `1`
- `KV` — число KV-heads
- `T` — длина компактного префикса в этом слое
- `D` — head_dim

Например, если:

```python
layers[0]["c1"].shape == (1, 8, 1248, 128)
```

это значит:

- batch size = `1`
- KV heads = `8`
- compacted length = `1248`
- head_dim = `128`

### Важный нюанс про padding

Внутри одного слоя все головы хранятся в тензоре одинаковой длины `T`, но реальные длины по головам могут различаться. Поэтому часть позиций может быть просто padding.

Padding устроен так:

- в `c1` и `c2` там нули
- в `beta` там `-inf`

Если коллега **не использует `beta`**, то просто брать весь `c1[:, :, :, :]` и `c2[:, :, :, :]` как есть может быть не совсем правильно, потому что padded хвост тогда превратится в обычные нулевые K/V позиции.

Поэтому правильнее перед использованием удалить padding по `beta`.

### Как восстановить реальные K/V без `beta`

Для каждой головы в каждом слое:

```python
mask = torch.isfinite(beta[0, head_idx])   # True на реальных позициях
K = c1[0, head_idx][mask]                  # (T_real, D)
V = c2[0, head_idx][mask]                  # (T_real, D)
```

То есть:

- `beta` не нужен как часть нового метода,
- но он нужен как **маска валидных позиций**, если хочется убрать padding корректно.

### Если совсем коротко

- `c1` = K
- `c2` = V
- `beta` можно не использовать как bias, но лучше использовать как маску, чтобы удалить padded позиции
